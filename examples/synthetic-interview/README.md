# 合成音声の再現検証

同梱の[合成インタビュー](deterministic_synthetic_interview_blind.mp4)を固定入力にして、粗いASR時刻から選ばれる音響候補と、反復音声の復号時刻を確認します。
音素ごとの開放時刻を確定した正解ラベルはなく、この例から破裂音検出の正解率は算出しません。

対象ファイルのSHA-256は次の値です。

```text
579bc0197f8bb03c0dc1d4250437d2fb7a77c074ec3829d7374718fe2055729c
```

[ルートREADMEの依存環境](../../README.md#validation)を準備し、リポジトリのルートで実行します。
Python 3.12、NumPy、SciPy、PyAVを使用します。

```bash
python scripts/evaluate_synthetic_acoustics.py --output /tmp/synthetic-acoustics.json
```

出力には各プローブの採否、候補時刻、除外理由と、反復音声の時刻検証結果を記録します。
`--output`を省略すると標準出力へJSONを出し、指定する場合はリポジトリ外のパスに限定します。
入力のハッシュ不一致、音声サンプルの欠落、反復音声の照合条件違反、後述するAPIの周期音を再び候補線に採用する回帰は終了コード1になります。

## 音響のみの独立レビュー

次の7プローブは、ASR時刻を探索の手掛かりにした診断用の区間です。
観測区間は、検出器の候補JSON、映像、旧検証動画、注入シフトを参照せず、波形とスペクトログラムから記録しました。
表のラベルは想定した語や音節を示し、生成音声にその音素が含まれることを保証しません。
時刻はすべて元動画の秒数です。

| 想定文脈 | 粗いASR時刻 | 観測された変化の範囲 | 音響所見 |
| --- | ---: | ---: | --- |
| Python | 11.380000 | 11.874–11.883 | 非周期成分の始まり。周期音の立ち上がりは11.916–11.926 |
| FastApp | 13.422500 | 13.315–13.324 | 小振幅の振動から周期音へ移行 |
| API | 14.413333 | 14.392–14.402 | 周期音の緩やかな立ち上がり。最初の有声パルスとの分離は困難 |
| pa | 18.100000 | 18.172–18.181 | 非周期成分の始まり。周期音の立ち上がりは18.209–18.221 |
| bu | 18.310000 | 18.305–18.327 | 継続中の周期音で振幅とスペクトルが変化 |
| backup-pu | 19.583333 | 19.613–19.624 | 低周波の周期成分が増大 |
| response-po | 21.040000 | 21.022–21.028 | 小さな低周波の動き。周期音の立ち上がりは21.030–21.034 |

いずれも、短い破裂の過渡成分を後続の有声パルスや持続する非周期成分から明確に分離できませんでした。
これらの区間は観測上の境界であり、確定した `/p/` や `/b/` の開放ラベルとして評価に使用できません。
明瞭な破裂が見えないことだけで、破裂音が存在しないとも判断できません。

最初のAPIでは、旧処理が14.395秒付近の周期音の立ち上がりを選びました。
短時間スペクトルの平坦度・高域成分の比率・局所音量を同じフレームで確認する処理を追加し、この立ち上がりを選択対象から除外します。
除外した候補と証拠値はJSON・CSVに残し、候補線は汎用の音量ピークへ戻しません。
14.614–14.624秒付近にも弱い非周期成分がありますが、対象子音との対応・開放時刻は未確認です。
表記を変えたローカルASRのアライメントも一致せず、この時刻へ手動で線を移す根拠にはしません。
この検証は誤採用の再発防止であり、正しい `/p/` 時刻の確定や精度の百分率を示すものではありません。

## 同じ発話を使ったサンプル時刻の検証

元の10.0–16.5秒の音声を含む反復区間について、安全な内側の11.0–15.5秒を48 kHzで復号して照合します。
予期する移動量の前後0.030秒を、平均を除いた正規化相互相関（NCC）で探索した結果は次のとおりです。

| コピー先の区間（秒） | コピー先での音声オフセット | 元区間からの音声移動量（秒） | NCC | 残差（サンプル） |
| --- | --- | ---: | ---: | ---: |
| 35.0–41.5 | 4フレーム遅延（24 fps） | +25.1666667 | 0.998927 | 0 |
| 42.5–49.0 | 5フレーム先行（24 fps） | +32.2916667 | 0.998805 | 0 |
| 50.0–56.5 | 変更なし | +40.0000000 | 0.999515 | 0 |

合格条件はNCCが0.95以上、予期する移動量との差が絶対値で0.003秒以下です。
3区間は同じ発話の再利用で、独立した音素事例には数えません。
この回帰テストが確認するのは、コードが復号音声のサンプル時刻を保つことです。
音素の開放時刻や、口唇映像との同期は検証していません。

## 旧注釈動画の扱い

[旧注釈動画](closure_evidence_video.mp4)のマーカーを元動画の時刻へ逆算した推定値は、FastAppで約13.56秒、レスポンスで約20.81秒でした。
後者は、対象としていた「ポ」のASR区間21.00–21.08秒や、独立レビューで観測した21.022–21.028秒と位置が一致していません。
0.2秒は24 fpsで約5フレームに相当し、閉鎖の判定対象となる原フレームも変わります。
この逆算は通常速度の音声照合と描画コードの固定0.8秒の前置きに基づき、フレーム配置と再符号化による不確かさを含みます。
推定値も旧動画も、音素時刻の正解ラベルとしては使用しません。

## 回帰テストで確認する動作

生成音声には確定した音素ラベルがないため、時刻が既知の制御信号でも検証します。
これらの信号は雑音パルスと正弦波で作り、日本語音素の認識率とは区別します。

- 対象区間の外にある強い立ち上がりで、対象語の候補を置き換えない。
- 語境界や重複区間の競合、近接していても無音で分かれたパルスは、曖昧さを残す。
- 候補の表示件数を1件にしても採否を変えず、選択した時刻をレビュー一覧に残す。
- 低周波の先行成分を、後続の広帯域の破裂候補より優先しない。
- 1–30 msで立ち上がる母音状の正弦波だけでは、破裂候補を自動採用しない。
- 強い周期音の後に弱い既知の雑音パルスがある場合は、後者を候補として残す。有声 `/b/` の先行周期成分も許容する。
- 同一語に複数の両唇音がある場合、同じ候補を重複して自動採用しない。
- 古い入力hash、順番を取り違えた候補、欠落音声内の注釈時刻を拒否する。
- 原フレームの欠落、口元測定の失敗、反復フレームがある窓を、接触が見えないだけで「閉鎖なし」にしない。観測できた接触は別途保持する。

検証は `python scripts/validate_repository.py` で実行できます。
Claude Code CLIのFable 5.1による実装を、別のレビューで作成した反例と合わせて検証しています。
同梱媒体は変更しておらず、旧注釈動画の再生成結果を示すものではありません。
